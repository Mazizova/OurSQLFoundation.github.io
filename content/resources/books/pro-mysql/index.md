*Pro MySQL* goes beyond MySQL's basic SQL syntax into its intermediate and advanced features — transaction processing, indexing theory, benchmarking and profiling, storage engine internals, stored procedures, replication, and how MySQL's own source code is organized.

Written by Jay Pipes and Michael Kruckenberg and published by Apress in 2005, it was written for developers and DBAs who already know standard SQL and want to understand what's happening underneath MySQL's query execution and storage layers.
