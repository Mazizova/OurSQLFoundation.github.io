*MySQL 8 Query Performance Tuning: A Systematic Method for Improving Execution Speeds* walks through a repeatable process for query tuning: monitoring execution times, identifying which queries are worth optimizing, analyzing their current execution plans, and improving them — using both the traditional `EXPLAIN` command and MySQL 8's `EXPLAIN ANALYZE`.

The author, Jesper Wisborg Krogh, has worked with MySQL since 2006 as an SQL developer, DBA, and member of the Oracle MySQL Support team, with a particular focus on performance tuning and the Performance and sys schemas. Published by Apress in 2020.
