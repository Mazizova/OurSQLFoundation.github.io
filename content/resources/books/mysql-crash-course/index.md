MySQL Crash Course walks beginner and intermediate database developers from installing MySQL through core SQL (queries, joins, data types) and on to stored procedures, triggers, and events, using three hands-on projects — weather, voter, and salary data — to practice each concept. Published by No Starch Press in 2023, it's aimed at readers who want a fast, practical path into MySQL rather than a full DBA reference.
