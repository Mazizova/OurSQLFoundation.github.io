*MySQL Concurrency: Locking and Transactions for MySQL Developers and DBAs* walks through how MySQL and InnoDB handle concurrent access — transactions, isolation levels, row and gap locks, and metadata/schema locks — and how to use the Performance Schema and Information Schema to diagnose lock contention and deadlocks.

The author, Jesper Wisborg Krogh, has worked with MySQL since 2006 as an SQL developer, DBA, and member of the Oracle MySQL Support team, with a particular focus on performance tuning and the Performance and sys schemas. Published by Apress in 2021.
