Percona Monitoring and Management (PMM) gives DBAs a single pane of glass over MySQL, MongoDB, and PostgreSQL fleets, combining Grafana dashboards, a Query Analytics (QAN) view for slow and expensive queries, and configurable alerting so performance regressions surface without jumping between separate tools.

PMM Server is released under the GNU AGPLv3, with the PMM Client under Apache 2.0. It ships as a Docker image (`percona/pmm-server`) and is developed by Percona alongside Percona Server for MySQL and Percona XtraBackup.
