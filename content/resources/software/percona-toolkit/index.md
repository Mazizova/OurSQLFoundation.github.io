Percona Toolkit bundles the command-line tools Percona's own support engineers use day to day — online schema changes (`pt-online-schema-change`), replica/table consistency checks (`pt-table-checksum`, `pt-table-sync`), and query analysis (`pt-query-digest`) among them — into a single collection so teams don't have to write and maintain the equivalent scripts themselves.

It's released under the GPL-2.0 license and actively maintained by Percona alongside their MySQL and Percona Server tooling.
