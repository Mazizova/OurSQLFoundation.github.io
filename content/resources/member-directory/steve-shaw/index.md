Steve Shaw is the founder of HammerDB and a former Intel Principal Engineer specializing in database performance on modern CPU architectures. He created HammerDB, an open source load-testing and benchmarking platform for leading relational databases, including MySQL, MariaDB, PostgreSQL, Oracle, SQL Server, and Db2. The project is hosted and sponsored by the Transaction Processing Performance Council. Steve's work focuses on realistic, reproducible database performance testing and making industry-standard benchmark workloads accessible to engineers and organizations.
